# AviaCare 🐦

## Swift Student Challenge 2026 Submission

AviaCare is an iOS application built using SwiftUI, designed to assist users in bird care and awareness. The app focuses on providing an intuitive and interactive experience to support bird well-being.

## ✨ Features

* Clean and intuitive SwiftUI interface
* Structured architecture (App, Data, Logic, Views)
* Focus on real-world problem: bird care and awareness

## 🛠 Tech Stack

* Swift
* SwiftUI
* Xcode

## 🎯 Purpose

This project was developed as a submission for the Apple Swift Student Challenge 2026.
